# dsa-2025

Personal practice log of data-structures and algorithms problems in Java, following the NeetCode roadmap (2025).

## Structure
```
neetcode/
  day-1/  AnagramChecker.java, ContainDuplicates.java, TwoSumPair.java, problems.txt
  day-2/  problems.txt   # Group Anagrams, Top K Frequent Elements, Encode/Decode Strings
```
Each `problems.txt` links the LeetCode problems for that day; solutions note their time and space complexity.

## Running a solution
```bash
cd neetcode/day-1
javac TwoSumPair.java && java TwoSumPair
```

## Topics so far
Arrays & hashing: duplicate detection, anagrams, two-sum.
